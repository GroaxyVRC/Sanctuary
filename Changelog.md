# Changelog

## October 2, 2026

### NPC interactions

Restored NPC prompts and interaction menus from captured game data. Added shared functions for other NPC interactions to use.

### Warpstones

Connected Warpstone NPCs to existing world objects so they can display names and open the atlas.

### Snowballs

Added the snowball-pile interaction, allowing players to pick up snowballs and use a temporary throwing ability.

### Boomboxes

Added a shared dance controller for player-placed boomboxes and permanent world boomboxes.

### Welcome screen

Added announcement and shop data to populate the welcome screen, with random Popular Items from the SC shop.

### Weapon flairs

Reviewed and cleaned up weapon-flair handling to match the repository’s existing code style.

### Code cleanup and performance

Cleaned up repeated code and naming. Improved resource loading, memory cleanup, and how data is sent to nearby players.
